# 早期写入器微基准

results.json 来自相同华为云服务器执行 main 的 tests/safepatch/run.sh。该脚本直接编译 base 的写入函数，与 main 的协作写入器比较，8 个工作线程，交替采集三对样本。C 目标使用 O0，Rust 驱动为 debug。样本窗口包含 20 次安装与恢复和固定保持时间。

本轮调用吞吐中位数为 base 53,857,434.30379803 次/秒、safe 19,734,343.09612101 次/秒，下降 63.35818192748677%。该结果覆盖写入器与协作协议的微基准，与正式整机实验分别报告。正式 16 轮及其受控业务负载见 ../2026-11-07/。
